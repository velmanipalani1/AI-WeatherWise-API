# AI WeatherWise – Project Planning

## Main Modules
- User authentication
- Favorite location management
- Current weather retrieval
- AI weather insights and recommendations
- MongoDB database
- REST API routes
- Authentication middleware

## User Flow
1. User registers or logs in.
2. User saves a favorite city.
3. User fetches current weather metrics.
4. User requests AI-driven weather insights.
5. System validates JWT and returns the requested information.
