# AI WeatherWise – Project Testing

The backend can be executed locally with MongoDB running and the required environment variables configured.

## Execution
```text
npm install
npm start
```

## API Testing
The documentation identifies API testing using Postman or Thunder Client and includes testing references for:
- Register API
- Login API
- Weather API
- Recommendation API

The `API-Testing-Screenshots` folder contains the testing screenshots extracted from the supplied project document.
